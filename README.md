🛠️ Installation

```bash
# Clone the repository
git clone https://github.com/THE-ERROR808/profile-yokai.git

# Navigate to the directory
cd profile-yokai

# Install dependencies
pip install -r requirements.txt

# Run Profile Yokai
python3 profile-yokai.py
```

📖 Usage Examples

Basic Profile Extraction

```bash
python3 profile-yokai.py username
```

Advanced OSINT Analysis

```bash
# Extract with intelligence augmentation
python3 profile-yokai.py username --stories --followers --following

# Export for security assessment
python3 profile-yokai.py username --json --csv
```

Industrial-Scale Intelligence

```bash
# Batch processing with parallel execution
python3 profile-yokai.py --batch user_list.txt --workers 20

# Monitor multiple accounts with real-time alerts
python3 profile-yokai.py username --monitor --interval 300
```

Enhanced Anonymity & Distribution

```bash
# Through Tor network
python3 profile-yokai.py username --tor

# With custom proxy rotation
python3 profile-yokai.py username --proxy http://proxy:8080
```

Interactive Intelligence Dashboard

```bash
python3 profile-yokai.py --dashboard
```
